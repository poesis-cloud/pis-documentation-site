# OIP — the Organizational Intelligence Platform

{: .no_toc }

The **Organizational Intelligence Platform (OIP)** is the first domain application built on **[SIE]({% link sie/index.md %})**. It is where all IT profiles converge — architects, developers, ops engineers, project managers, security officers, compliance analysts — to define, govern, regulate and supervise the IT landscape through a single governed source of truth.

From that truth, OIP generates IT artifacts, simulates impacts, and evaluates compliance against any governance or regulatory framework sourced into **[GSM]({% link gsm/index.md %})**.

## Products

- **[Web Application]({% link oip/web-application/index.md %})** — the application every IT profile works in, for defining, governing, regulating, and supervising the IT landscape. Start with **[Getting Started]({% link oip/web-application/getting-started.md %})**, then **[General Usage]({% link oip/web-application/general-usage.md %})** and the role-specific **[Usage Scenarios]({% link oip/web-application/usage-scenarios/index.md %})**.

Truth sourcing — keeping IT information aligned with reality as GSM Definitions — is provided by **[SIS]({% link sis/index.md %})** and its **[Code Sourcer]({% link sis/code-sourcer/index.md %})**.
