# SIS — Systemic Intelligence Sourcing

{: .no_toc }

**Systemic Intelligence Sourcing (SIS)** sources **[GSM]({% link gsm/index.md %})** definitions from external artifacts — starting with code repositories — through a collaborative blackboard. Every sourced definition enters the model as an evidence-backed DRAFT contribution, carrying its confidence and provenance, and feeds the **[SIE]({% link sie/index.md %})** **[Definition Manager]({% link sie/definition-manager/index.md %})**, so a human remains the trust boundary.

## Products

- **[Code Sourcer]({% link sis/code-sourcer/index.md %})** — sources definitions from code repositories, API contracts, and infrastructure, posting them as contributions to the Blackboard Manager. *Documentation in construction.*
- **[Blackboard Manager]({% link sis/blackboard-manager/index.md %})** — the collaborative definition-sourcing service, with sealed blackboards, a byte-stable contribution lifecycle, and an append-only audit ledger. *Documentation in construction.*
