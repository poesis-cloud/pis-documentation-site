# MCP

{: .no_toc }

> **In construction.** This product is at an early stage; its documentation will follow its first release.

**MCP** is the planned **Model Context Protocol** server for SIE. It is intended to give AI applications and agents governed context — policy-filtered, pinned definitions held by the **[Definition Manager]({% link sie/definition-manager/index.md %})** and bounded operations — through the Model Context Protocol, alongside direct API access. Nothing is implemented yet.

## Roadmap

| Feature | Representative content | Milestone |
|---------|------------------------|-----------|
| Governed AI context for agents via MCP | The governed model and its tooling served to AI applications and agents via the Model Context Protocol — definitions as typed, trustworthy context | v1.0 (MVP/GA) |
