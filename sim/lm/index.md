# LM

{: .no_toc }

> **In construction.** This product is at an early stage; its documentation will follow its first release.

**LM** is the SIM language model. Its planned v1.0 (MVP/GA), **GSM/SIE-grounded language models**, trains language models on **[GSM]({% link gsm/index.md %})** definitions and **[SIE]({% link sie/index.md %})** governed context and aims to show whether they outperform the same models given any other context. This is planned research: no model is released and no advantage is claimed yet. See **[Milestones & Versions]({% link milestones.md %})** for the canonical version semantics.
