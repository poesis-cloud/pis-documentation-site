# SIM — Systemic Intelligence Model

{: .no_toc }

The **Systemic Intelligence Model (SIM)** is an early-stage effort toward a language model grounded in **[GSM]({% link gsm/index.md %})** definitions and **[SIE]({% link sie/index.md %})** governed context. Nothing is released yet.

## Products

- **[LM]({% link sim/lm/index.md %})** — the SIM language model, exploring whether language models trained against GSM / SIE governed context perform better than with any other context. *Documentation in construction.*
